About / 關於教學包

The
story.

「NEXT GEN」是一支 3 分 38 秒的音樂影片，沒有用影片生成 AI，每一格畫面都是程式算出來的：Claude 用網頁的 3D 技術（three.js）寫出畫面，讓瀏覽器一格一格算成圖片，再用 ffmpeg 接成影片。Popo 沒有程式背景，負責寫劇本、分鏡、看每一個版本、提出修改，也決定用哪些資料和數字；Claude 負責寫程式、設計畫面細節和動態、查資料。從 2026/10/26 到 11/12，在同一個對話裡來回約 450 回合，從第一版粗剪一路改到 v64 成片，另外做了英文版、2K 主視覺和 29 秒的社群短版。

這份教學照製作的先後排成 16 章（第 00 章是導讀）。每一章都分成四塊：當時要解決什麼、Popo 怎麼下指令、做出什麼、從中學到什麼。Popo 的指令一律用原文，錯字和標點都照原樣；Claude 的部分只寫摘要。段落旁的「看素材」按鈕會打開當時的定格、靜音短片、指令原文和版本對照，看得到每一次修改前後差在哪裡。

→你會看到很具體的做法

  • 怎麼先把配樂拆成段落，再用「第幾小節」跟 Claude 講時間。
  • 怎麼用一張參考圖說明喜歡的樣子，再把「為什麼好看」整理成之後每一段都照著做的設計準則。
  • 雲端沒有顯示卡、一段 23 秒的動畫要算約 35 分鐘時，怎麼把渲染搬到自己的電腦。
  • 一個叫不出名字的數字效果，怎麼前後改了 8 版才定下來。
  • 做完畫面之後，怎麼回頭驗算 MV 裡的數字。

這不是「一鍵生成」的教學。照復刻條件頁的說法，時間大多花在「看新版本、找出要改的地方、寫成指令」這個循環，而這份教學記錄的就是這個循環一輪一輪怎麼進行。

How to use / 怎麼使用

How it
works.

  1. 購買後，從雲端硬碟下載 zip 檔（約 93 MB）。
  2. 先把 zip 解壓縮（Windows：在檔案上按右鍵 →「全部解壓縮」）。不要直接在 zip 裡面點開，圖片和影片會讀不到。

FAQ / 常見問題

Ques
tions.

Q1不會寫程式，看得懂嗎？

Popo 自己沒有程式背景，這份教學也從他的角度寫：重點是怎麼描述畫面、怎麼看每一個版本、怎麼提修改，不講程式碼。第 00 章先解釋後面常出現的詞，例如小節、卡點、渲染、子代理。復刻條件頁也寫了：不需要會寫程式，但要能照著步驟安裝軟體、找到資料夾。

Q2需要付費的 Claude 方案嗎？

只是讀這份教學，不需要任何帳號。想照著做一支自己的 MV，復刻條件頁寫的是每月 20 美元的 Claude 付費方案就可以（Popo 自己用的是 Max 5x 方案）。20 美元方案的用量額度比較少，照 Popo 每天 2～3 小時的製作速度，可能會碰到額度上限、要等額度恢復，整體製作時間會拉長一些。其他用到的軟體（Node.js、Playwright、ffmpeg、three.js 等）都是免費的。

Q3電腦需要很好嗎？

這支 MV 是在 Popo 自己有獨立顯示卡的 Windows 桌機上算的，規格寫在復刻條件頁。沒有獨立顯示卡也能算，只是會慢很多；第 05 章就是在講雲端算太慢，才改成在自己的電腦算。

Q4有原始碼嗎？

第一版沒有。這份教學包的重點是製作過程：指令原文、各版本的畫面、設計準則，以及踩過的坑和解法。

Q5影片為什麼沒有聲音？

MV 的配樂是別人的作品，不能跟著教學包散布，所以短片都已移除聲音。為了讓你還是看得出畫面有沒有「卡點」，短片下方有一條拍點列：白色長線是每一小節的開頭，短線是拍子，紅點是特別要卡的重拍，紅色直線是目前播到的位置。

Q6會更新嗎？

教學包首頁右上角有版本號和更新日期，目前是 v1.1（2026-11-13 更新）。
